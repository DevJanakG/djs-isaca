# PROJECT SPEC - DJS ISACA: THE HUNT

## Concept
The user is not browsing a hackathon site. They are being recruited as a hunter into a supernatural case.

Hackathon vocabulary:
- Participants -> Hunters
- Tracks -> Cases
- Problems -> Investigations
- Prizes -> Bounties
- Rules -> Hunter's Code
- Judges -> Council
- Sponsors -> Allies
- Schedule -> Case Timeline
- Registration -> Join the Hunt (Happens via unstop, no form)

## Story flow

### S00 0-8% - Darkness / recruitment
Black screen, flashlight pointer, hidden scratches, EMF escalation.

### S01 8-23% - Highway
Night road, generic black classic car silhouette, fog, trees, title reveal, road sign/radio message.

### S02 23-34% - Case file
World flattens/transforms into aged paper/journal. Explain hackathon.

### S03 34-48% - Investigation board
Tracks are evidence/case files connected with red string.

### S04 48-57% - Archive
Benefits, mentorship, networking, bounty/prizes as classified archive entries.

### S05 57-70% - Bunker hub
Schedule, rules, prizes, venue and FAQ.

### S06 70-76% - Encounter
Shadow/entity moment and salt containment interaction or simplified equivalent.

### S07 76-84% - Judge dossiers
Judge cards reveal like classified files/polaroids.

### S08 84-90% - Allies/artifact vault
Sponsor logos displayed respectfully in a dark vault/plinth treatment.

### S09 90-96% - Possession / portal
Brief controlled glitch, emergency lighting, portal/noise/particles.

### S10 96-100% - Finale
Silence/darkness. "So... are you in?" Event details. JOIN THE HUNT CTA.

## Persistent elements
- Hunter's Journal navigation.
- Small EMF indicator.
- Sound toggle.
- Optional clues found counter 0/7.

## Visual palette
- near black: #050505
- charcoal: #181818
- dried blood accent: #772222
- aged paper: #d7c5a1
- tungsten: #e8a94e
- desaturated green: #899b84

Do not hardcode these everywhere; expose CSS variables.

## Information placeholders
Keep event facts in a central data file so organizers can update them without touching scene code:
- official event title;
- date/time;
- duration;
- venue;
- registration URL;
- team size;
- eligibility;
- tracks;
- prizes;
- schedule;
- rules;
- judges;
- sponsors;
- FAQ;
- contacts/social links.

## Success definition
A visitor should understand the event and registration path even if 3D is disabled, but on a capable desktop the first minute should feel like a cohesive interactive supernatural title sequence.
